# AI Fiction — 完整生命周期设计文档 v3

## 一、核心理念

```
这不是一个"一键生成小说"的工具。
这是一个陪着你从零开始，一步步把故事养大的创作伙伴。

每一个环节都是真实的、持续的、可迭代的。
不存在"生成完事"，只有"生成了→看了→调了→再生→继续写"。
```

## 三、设定期 — 创作向导

```
我吐一个字 → AI 出内容 → 我确认/微调 → 永久入库 → 下一步

全程真实数据写入 Project/Character/WorldSetting/Outline 表，
不存在"草稿"，每步完成即刻生效、即刻可见。
```

## 四、写作期 — 逐章 AI 协作

进入项目工作台，已有完整大纲 + 30 章空白章节。

```
工作台 = 左侧章节列表 + 中间编辑器 + 右侧 AI 面板

                    ┌─ 章节列表 ──────┐  ┌─ 内容编辑 ──────────┐  ┌─ AI 面板 ────┐
```

### 写作模式

**① 逐章交互式写作**（推荐）
```
点"写第3章" → AI 写 → 5~30秒出内容 → 即时显示在编辑器
  → 看了不满意 → 点"重写" → 生成新版本
  → 看了还行但想改改 → 编辑器直接修改文字
  → 满意 → 点"完成"
```

**② 批量自动写作**
```
点"一键生成全部 30 章" → 后台逐个生成
  → 可以离开，回来看结果
  → 每章独立版本，不喜欢的单独重写
```

### 每章写作时 AI 带上的上下文
```
写第 10 章时，AI 自动带上：
  ✅ 世界观设定（六维度约束卡）
  ✅ 角色当前状态（关系卡 + 行为约束卡）
  ✅ 最近 3 章的完整内容（滚动窗口）
  ✅ 本大纲节点的写作指南
  ✅ 本章需要埋/揭的伏笔提示
```

### 章节配置（每章可独立设置）
```
本章目标字数：[3000 ▾]（2000/2500/3000/4000/5000）
写作风格：     继承项目全局 / 本章自定义
视角切换：     继承全局 / 本章自定义
```

## 五、打磨期

全书 30 章全部标"已完成"后：

```
[🔍 开始全面审查]
  → 连续性检查（时间线、道具、地点）
  → 角色一致性（言行是否符合设定）
  → 情节逻辑（因果是否成立）
  → 节奏分析（哪些章太拖、哪些章太赶）
  → 伏笔回收验证（埋了的是否都揭了）

AI 输出审查报告 → 逐条修复 / 批量自动修复

[✨ 全局润色]
  → 按严重程度分组修复
  → 统一文风
  → 消除重复用语
```

## 七、API 设计

### 向导阶段（设定期）

```
POST /api/v1/projects
Body: { genre, target_length, story_suggestion, interests }
→ 创建 Project + 空 WorldSetting
→ asyncio 后台生成书名梗概 → 更新 Project.title/story_brief/writing_style
→ 返回 { project_id }


POST /api/v1/projects/{id}/wizard/step/{step}
step ∈ {world, characters, outline}

world:
  → 后台生成世界观 → 写入 WorldSetting
  → 请求可带 { target_word_count? } 设置每章字数

characters:
  → 后台生成角色+关系 → 创建 Character × N

outline:
  → 后台生成大纲+伏笔 → 创建 Outline + OutlineNode + ForeshadowingPlan + Chapter × N(状态=planned)
  → 每章 Chapter 记录带上目标字数


GET /api/v1/projects/{id}/wizard/status/{task_id}
→ { status, progress, progress_message }
```

### 写作阶段

现有 API 已经完善（chapters/generation/quality）。

投影到向导流：
```
GET  /api/v1/projects/{id}/chapters          → 章节列表（含状态、字数）
POST /api/v1/projects/{id}/generation/start  → 批量生成
POST /api/v1/projects/{id}/generation/chapter → 单章生成
POST /api/v1/projects/{id}/generation/polish  → 润色
POST /api/v1/projects/{id}/generation/modify  → AI 按指令修改
```

## 八、数据模型（零新表）

| 表 | 存储内容 | 对应步骤 |
|----|---------|---------|
| `Project` | + wizard_step (1~4 nullable) | Step 1 创建 |
| `WorldSetting` | original/expanded/structured | Step 2 写入 |
| `Character` | 角色档案 + 关系 | Step 3 写入 |
| `Outline` + `OutlineNode` | 大纲结构 + 章节计划 | Step 4 写入 |
| `ForeshadowingPlan` | 伏笔 | Step 4 写入 |
| `Chapter` | 章节内容 + 字数 + 状态 | Step 4 批量创建(planned) → 写作期逐章填充 |

唯一新增：Project.wizard_step 字段（int 1~4）。
唯一新增路由：`/wizard/step/{step}` + `/wizard/status/{task_id}`。
