# 使用手册

AI Fiction Studio 的核心流程是：

```text
项目策划 -> 世界观 -> 角色/势力 -> 全书大纲 -> 卷轴弧线 -> 章节蓝图 -> 正文写作 -> 质量审计 -> 修复 -> 记忆沉淀
```

## 1. 项目策划

入口：`/projects/create`

项目策划对话用于把零散想法变成稳定项目方案。你可以从很粗的描述开始：

```text
我想写一个轻松搞笑的都市异能文，主角能预知社死事件，每次躲避反而让场面更离谱。
```

AI 会逐步整理：

- 核心引擎：故事持续产生冲突的机制。
- 读者承诺：读者追读时期待获得什么。
- 主角驱动力：主角为什么必须行动。
- 边界锁定：哪些设定不能违背。
- 长篇规划：适合短篇、中篇还是长篇连载。

创建项目后，这些策划信息会进入项目记忆，影响后续世界观、大纲和章节生成。

## 2. 项目向导

入口：`/projects/:projectId/wizard`

项目向导负责完成开书前的基础资产：

- 生成世界观。
- 生成角色势力。
- 生成全书大纲。
- 应用草稿到项目。

建议顺序：

1. 先聊清项目方案。
2. 生成世界观并补充硬约束。
3. 生成角色和势力，检查主角、反派、恋人、关键配角是否齐全。
4. 生成全书大纲。
5. 进入工作台拆卷和写作。

## 3. 工作台

入口：`/projects/:projectId`

工作台是日常写作主界面，分为三块：

- 左侧：目录、卷、弧线、章节。
- 中间：章节正文编辑器。
- 右侧：写作参考，包括角色、势力、大纲等。

### 卷轴操作

在左侧展开卷后可以操作：

- `展开弧线`：把本卷拆成若干叙事弧线。
- `重拆整卷弧线`：重新规划本卷弧线。
- `AI调整故事大概`：只调整卷概要，不改章节和弧线。
- `AI调整本卷`：通过对话调整本卷后续大纲。
- 弧线内 `重写` / `拉长` / `压缩`：调整某条弧线。
- `展开章节`：把弧线拆成具体章节。
- `批量写`：批量生成弧线内章节。
- `评审`：评审弧线结构。

### 对话式调整

卷轴和大纲页都支持“对话沟通后再调整”：

1. 点 `AI调整故事大概` 或 `AI调整本卷`。
2. 在左侧对话区说你的感受。
3. AI 会整理成右侧的 `最终调整要求`。
4. 你确认后点 `开始调整`。

这适合处理：

- 概要太文学化。
- 弧线太散。
- 前 20 万字吸引力不足。
- 主角目标不明确。
- 反派压力不足。
- 爽点和钩子不够。

## 4. 写作设置

章节工具栏提供可读性和写作控制：

- `通俗易懂`：降低理解成本，适合多数网文正文。
- `简单直白`：进一步减少隐喻、长句和复杂心理说明。
- `正常`：平衡画面、动作、对白和解释。
- `烧脑细腻`：提高信息密度和细节密度。

写作设置还包括：

- 节奏模式。
- 对白密度。
- 描写密度。
- 幽默程度。
- 信息密度。
- 标点风格。
- 章节模板。
- 前期抓人模式。
- 自动质量检查。
- 自动轻修。

## 5. 章节生成

选择一个章节后点击 `写本章`。

生成时系统会组织以下上下文：

- 项目简介和策划记忆。
- 世界硬约束和文风规则。
- 角色状态和语言指纹。
- 势力信息。
- 时间线和伏笔。
- 当前卷目标。
- 当前章节蓝图。
- 最近章节摘要和状态。

AI 输出后会写入正文编辑器，你可以继续手动修改。

## 6. 章节优化

正文工具栏提供：

- `改易懂`：降低理解成本，减少绕和抽象。
- `对白`：优化对白自然度和角色辨识度。
- `标点`：修复中文标点、引号、省略号、破折号等问题。
- `去AI味`：减少模板句、抽象总结和机械段落。
- `画面感`：补充可见动作、场景定位和必要细节。
- `强钩子`：增强章末或段落结尾悬念。
- `强追读`：强化下一章阅读动机。

## 7. 质量审计

点击章节工具栏 `审计`，系统会返回：

- 总分。
- 是否通过。
- 亮点。
- 问题清单。
- 问题定位原文。
- 严重度。
- 修复建议。
- 推荐修复范围。

审计维度包括：

- 可读性。
- 标点。
- 对白。
- 场景清晰度。
- 角色一致性。
- 钩子。
- AI 味。

## 8. 问题修复

审计后可以选择：

- `只修原句`：只替换定位句或短语。
- `修这一段`：重写定位段落。
- `深修此问题`：重写目标段落及前后局部上下文。
- `按审计轻修`：整章轻量修复，不改核心剧情。
- `按审计重写`：依据审计结果重写整章，会覆盖正文但保存版本。

选择建议：

| 问题类型 | 推荐方式 |
|---|---|
| 标点、错字、短句别扭 | 只修原句 |
| 一段读不懂、信息表达混乱 | 修这一段 |
| 物品突然出现、动机缺铺垫、上下文断裂 | 深修此问题 |
| 全章 AI 味重、阅读阻力大 | 按审计轻修 |
| 章节方向整体失败 | 按审计重写 |

## 9. 质量仪表盘

入口：`/projects/:projectId/quality-dashboard`

质量仪表盘用于跨章节查看问题：

- 质量评分分布。
- 章节问题清单。
- 可修复问题。
- 重新审计定位。
- 整章轻修。
- 标记修复完成。

老审计数据如果缺少可定位原文，可以先点 `重新审计定位`。

## 10. 记忆中枢

入口：`/projects/:projectId/memory-center`

记忆中枢集中展示：

- 项目策划记忆。
- 世界规则。
- 角色当前状态。
- 伏笔。
- 时间线事件。
- 章节记忆。
- 写作风险。
- 组织和势力信息。

它不是聊天记录页面，而是“写作上下文资产库”。

## 11. 图谱与景观

系统提供多个结构查看页面：

- `故事线`：查看叙事线索和章节连接。
- `叙事图谱`：查看关系边与因果连接。
- `小说景观`：查看关键事件景观线、卷章泳道等。
- `预览`：阅读已写正文。

这些页面用于检查长篇结构是否清晰、事件是否重复、角色是否缺席、因果是否断裂。
