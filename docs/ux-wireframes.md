# AI Fiction Studio — UX 线框图与交互设计 v1

> 设计目标：**写作者的工具，不是开发者的工具**。每一个交互都要让写作更流畅，
> 每一个 AI 调用都要让用户有掌控感，每一处设计都要可快速修改。

### 1.2 字体系统

```
标题：Archivo（英） / 思源黑体 Bold（中）

字号层级：
  h1  32px/40px   — 页面标题
  h2  24px/32px   — 区域标题
  h3  18px/28px   — 卡片标题
  body 16px/24px  — 正文
  sm  14px/20px   — 辅助文字
```


### 2.2 核心设计原则

```
原则 1：所见即所改
  → 任何内容直接点击即可编辑，不需要进"编辑模式"
  → 内联编辑 > 侧边抽屉 > 模态框 > 新页面

原则 2：AI 是副驾驶，不是黑盒
  → AI 生成的内容永远有"为什么这样生成"的解释
  → 每次生成都有"接受 / 微调 / 重来"三个选项

原则 3：状态永远自动保存
  → 没有任何"保存"按钮
  → 每次修改自动同步到后端
  → 离开页面前零确认（数据不会丢）

原则 4：键盘即效率
  → 所有高频操作都有快捷键
  → Cmd+K 全局命令面板
  → Cmd+Enter 触发 AI 生成

原则 5：渐进式复杂度
  → 默认只展示核心字段
  → "展开高级"才显示完整配置
  → 新手友好 + 专家可控
```

### 关键交互

| 元素 | 交互 |
|------|------|
| **字数滑块** | 拖拽实时更新下方表格，松开后 300ms debounce 重新计算分配 |
| **分配表格** | 每行可点击 ✏️ 进入内联编辑（直接改数字），失焦自动重算总和 |
| **书名输入框** | 右侧 ♻️ 按钮单独让 AI 重新生成书名（不影响其他内容） |
| **梗概输入框** | 自动撑高（min 3行），右下角实时字数统计，超出变红 |
| **风格标签** | 点击 × 删除，点击「+添加」弹出搜索下拉（已有标签灰色不可选） |
| **确认按钮** | 保存全部 → 顶部步骤条 Step 1 变 ✅ → 自动滚动到 Step 2 |

### 进度条状态

## 十四、动画规范

```
页面过渡：
  路由切换：fade 200ms + slide-up 150ms（子元素 stagger 50ms）

组件动画：
  模态框打开：scale(0.95)→scale(1) + fade，200ms ease-out
  模态框关闭：scale(1)→scale(0.95) + fade，150ms ease-in
  抽屉/面板：slide-in-right / slide-out-right，250ms
  Toast：slide-in-right 300ms，slide-out-right 200ms
  列表项：stagger fade-in-up，每个延迟 30ms

微交互：
  hover：transition-all duration-150
  按钮按下：scale(0.97)
  开关：背景色 transition-colors duration-200
  复选框：border→fill + checkmark draw，150ms

AI 生成：
  按钮 → spinner：morph 200ms
  内容流式输出：逐字显示，无动画延迟（实时渲染）
  骨架屏：shimmer 从左到右，1.5s 循环

滚动行为：
  导航点击 → 目标元素：smooth scroll，500ms
  章节间跳转：编辑器内容 crossfade，300ms

尊重系统设置：
  @media (prefers-reduced-motion: reduce) {
    *, *::before, *::after {
      animation-duration: 0.01ms !important;
      transition-duration: 0.01ms !important;
    }
  }
```

## 十五、AI 交互 UX 原则

```
原则 1：AI 永远给出理由
  ✗ "建议把这段删掉"
  ✓ "这段重复了第3章的设定，建议精简——第3章已经交代过灵根体系"

原则 2：AI 建议永远可逆
  → 每个 AI 修改都有 [应用] [预览差异] [忽略] 三个选项
  → 版本历史自动记录每次 AI 修改前的状态

原则 3：AI 不替代用户决策
  → AI 可以"建议"但不能"替你决定"
  → 关键设定（角色死亡、主线转折）AI 必须标注 ⚠️ 并等待确认

原则 4：AI 进度透明
  → 批量生成时显示：当前进度 + 预计剩余时间 + 可随时暂停
  → 每章生成后立即在导航栏标记状态

原则 5：AI 学习你的偏好
  → 用户反复拒绝同类型建议 → AI 自动调整建议策略
  → 用户反复修改同类内容 → AI 提问"要不要我以后都按照你的风格来？"
```

```
               │                         ↑
```
